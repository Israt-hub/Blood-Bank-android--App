Blood Bank Android Application 🩸

An Android application designed to connect blood donors with people in need of blood donations quickly and efficiently.

## Key Features
  User Registration & Login:** Secure authentication for donors and recipients.
   **Find Donors:** Search for available blood donors based on blood group (A+, B+, O+, AB+, etc.) and location.
   **Blood Request:** Post urgent blood requests with patient details and hospital location.
  **Donor Profile:** Manage donor availability status and contact information.
  **Direct Contact:** Call or message donors directly from the app in case of emergencies.

## 🛠️ Technologies Used
* **Language:** Java 
* **UI Design:XML
* **Database:** Firebase 
* **IDE:** Android Studio

##  How to Run the Project
1. Clone or download this repository.
2. Open the project in **Android Studio**.
3. Let Gradle sync all the required dependencies.
4. Run the app on an Android Emulator
